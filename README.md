Bush flying in the **Kestrel K-2**, a high-wing single over the Halcyon river valley: two
airfields, a winding river, forested ridges and four sorties that each ask something different.

- **River Ring Trail** — thread 10 rings down the river against the clock.
- **Pinecrest Mail Run** — take off with 40% fuel, cross the ridge, land on the short strip.
- **Ridge Beacon Recon** — log four ridge-top beacons below 200 m AGL, then land back home.
- **Free Flight** — full tanks, both fields, practise landings.

Physics: lift with stall past the critical angle of attack, induced and parasitic drag, flaps,
brakes, fuel burn tied to throttle, overspeed damage, and every touchdown graded by sink rate and
bank (smooth, firm, hard, off-field, crash). Chase camera or a cockpit with six lit gauges.

## Controls

| | |
|---|---|
| W / S, A / D | pitch, roll (or hold the left mouse button and steer) |
| Q / E | rudder |
| Shift / Ctrl, mouse wheel, 1–9 and 0 | throttle |
| F | flaps (up, 10°, 25°) |
| B or Space | brakes |
| C | chase / cockpit |
| P, R, M | pause, restart, sound |

## Run

```sh
node serve.ts                               # play at http://localhost:8080
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts   # build the hand-in
```

`game/` is static files with no build step and no network. The only library is three.js r170
(MIT, © 2010–2024 three.js authors), vendored as `game/vendor/three.module.min.js`. Everything
else (terrain, aircraft, instruments, sound) is generated by this repository's code.
Screenshots are the game's own renders, taken with `tools/capture-shots.mjs`.
